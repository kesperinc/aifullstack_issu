## 📌 프로젝트 개요

본 저장소는 **KG ICT (KGM 모빌리티 IT 담당)**를 대상으로 제안하는 **『차세대 온프레미스/하이브리드 Coding Agent 기반 KGM 자동차 모델별 BOM 인텔리전스 챗봇 구축 사업』**의 공식 제안서 및 프레젠테이션 산출물을 관리합니다.

본 프로젝트는 과거 **현대자동차 남양연구소**와 성공적으로 완수한 *'자동차 모델별 BOM 확인 및 검색 챗봇 PoC'*의 도메인 지식과 노하우를 계승하고, 2026년 최신 AI 기술 패러다임(**Text-to-SQL 탈피**, **자가수정 Code-Interpreter 에이전트**, **컨테이너 표준 플랫폼 기반 On-Prem/Public 하이브리드 지원**, **모델 경량화 코딩 특화 sLLM & 초고속 추론 서빙 엔진**, **임베디드 OLAP + Graph DB 듀얼 인메모리 데이터 레이어**)을 적용하여 KGM 모빌리티와 KG ICT에 최적화된 차세대 사내 Private BOM 인텔리전스 시스템을 제안합니다.

## 🚀 핵심 아키텍처 및 기술 차별화 요약

1. **상호 데이터 준비(Data Readiness) 선행 내재화**:
   - 실무 프로덕션 성공을 위해 KGM 현업과 KG ICT 간의 **상호 데이터 스키마 정의, 부품 코드 표준화, 결측치 및 테이블 정제 단계**를 1개월차 정규 공정으로 편성하여 90% 이상의 높은 정합성을 보장합니다.
2. **컨테이너 표준 AI 플랫폼 기반 인프라 유연성 (On-Premise & Public Cloud)**:
   - 특정 외산 상용 솔루션 종속에서 탈피하여, **쿠버네티스 기반 엔터프라이즈 표준 AI 플랫폼**을 아키텍처 기반으로 삼아 사내 전산실 **On-Premise** 배포와 **Public Cloud** 확장을 모두 유연하게 지원합니다.
3. **초경량화 코딩 특화 모델(sLLM) & 초고속 추론 서빙 엔진**:
   - 구조적 프루닝 및 정밀 양자화(INT4/FP8)를 거친 **초경량 코딩 특화 모델(sLLM)**과 **프리픽스 캐시 재사용 및 메모리 최적화 기반 초고속 서빙 엔진**을 결합해 다단계 에이전트 추론 지연을 70% 단축합니다.
4. **임베디드 OLAP + 임베디드 Graph DB 듀얼 인메모리 데이터 레이어**:
   - **인프로세스 임베디드 OLAP 엔진**(수백만 건 BOM 수치 집계 및 사양 Diff 연산)과 **인프로세스 임베디드 Graph DB**(완성차-모듈-단품 다계층 BOM 트리 순회 및 대체 부품 경로 탐색)를 **제로카피(Zero-Copy) 공유 메모리 파이프라인**으로 통합하여 초고속 분석을 수행합니다.
5. **멀티모달 & 인터랙티브 인터페이스 혁신**:
   - **Voice-to-BOM (음성 검색)**: 온프레미스 신경망 STT 엔진을 통해 연구실 및 현장에서 핸즈프리 마이크 음성 질의를 지원합니다.
   - **계층적 드릴다운(Drill-down) 트리 UI**: 완성차부터 단품까지 이어지는 부품 계층 트리를 시각적으로 펼쳐가며 자연어 대화와 마우스 클릭을 양방향 연동합니다.

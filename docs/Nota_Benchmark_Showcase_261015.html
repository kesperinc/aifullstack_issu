내용 수정
이 파일을 메모장·VS Code로 열면 상단 const CASES = [ … ] 배열에 사례별 문구와 수치가 모여 있습니다. 이 부분만 고치면 화면이 바뀌고, 항목을 넣거나 지우면 슬라이드 수도 자동 반영됩니다
자동 순환 간격은 AUTO_MS(기본 13000 = 13초), 자동 복귀 대기는 IDLE_MS(기본 75000 = 75초)
GPU 대수 연출은 gpu:{b:8, a:2, u:'장'}, 숫자 카운트업은 count:[시작, 끝, 소수자리] 로 지정합니다

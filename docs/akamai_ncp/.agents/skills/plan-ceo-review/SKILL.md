# /plan-ceo-review - 비즈니스 임팩트 및 가치 검토 워크플로우

본 스킬은 작성된 AKAMAI & NVIDIA 공동 사업 계획안의 비즈니스적 타당성과 파급력을 CEO 관점에서 종합 평가하여, 사업 계획의 완성도를 10점 만점 기준으로 진단하고 개선책을 제시하기 위해 작동합니다.

---

## 1. 평가 및 진단 기준 (CEO Rubric)

에이전트는 사업 계획 문서를 읽고 아래 **5가지 비즈니스 차원**에 대해 각각 0~10점의 점수를 부여하고 구체적인 근거를 서술해야 합니다.

### 1) 가치 제안의 명확성 (Value Proposition Clarity)
- "왜 고객이 기존의 다른 GPU 클라우드를 두고 본 결합 플랫폼을 선택해야 하는가?"가 논란의 여지없이 뾰족하고 명확하게 서술되어 있는가?

### 2) 파트너십 시너지 극대화 (Partnership Synergy)
- AKAMAI의 글로벌 분산망 강점과 NVIDIA의 AI 연산 기술 강점이 기계적 결합을 넘어 상호 보완적인 화학적 결합을 이루고 있는가?

### 3) 재무 및 비용 타당성 (Financial Viability)
- 인프라 투자 비용(CapEx), 운영 비용(OpEx), 특히 타 클라우드 대비 Egress 비용 절감 효과가 구체적인 데이터나 모델을 통해 정량적으로 시뮬레이션되어 있는가?

### 4) 시장 진입 및 확장성 (GTM & Scalability)
- 초기 고객 확보 전략(Landing)이 구체적이며, 신속하게 글로벌 스케일로 확장할 수 있는 파이프라인이 제시되어 있는가?

### 5) 리스크 관리 및 대응성 (Risk Mitigation)
- GPU 자원 공급망 한계, 네트워크 보안 위협, 현지 컴플라이언스(규제) 대응 방안이 실효성 있게 마련되어 있는가?

## 2. 리뷰 결과물 작성 가이드라인

평가 결과는 **`docs/proposal/ceo_review_verdict.md`** 파일에 한국어로 작성되어야 하며, 다음 구조를 따릅니다.

### 1) 종합 판정 (Executive Verdict)
- 계획서가 통과(Go) 가능한 수준인지, 아니면 전면 수정(Pivot/Retry)이 필요한지에 대한 최종 판정 의견.

### 2) 평가 점수표 (Scorecard Table)
| 평가 차원 | 점수 (0-10) | 현재 상태 요약 | 10점을 만들기 위한 개선 요구 사항 |
| :--- | :---: | :--- | :--- |
| 가치 제안 | | | |
| 파트너십 시너지 | | | |
| 재무 타당성 | | | |
| 시장 진입 | | | |

### 3) 10점 만점을 위한 액션 아이템 (Path to a "10")
- 각 영역에서 최상위 등급(10점)을 받기 위해 오늘 당장 수정해야 할 핵심적인 기획 보완 조치 사항 3가지 핵심 요약.

## 3. MZC 매출 80% AWS 기반 '컴퓨트 매입 전환(Repatriation)' 수익성 정밀 점검

### 3.1. AWS 컴퓨트 매입 모수 역산 및 '1/4(25%) 전환'의 물리적 용량 검증

메가존클라우드의 CSP 리셀 구조를 기준으로 별도 법인(대구 AIDC 인프라 법인)으로 이전 가능한 컴퓨트 물량과 전력 용량(MW)의 상관관계를 산출했습니다.

1. **MZC 내 AWS 컴퓨트 원가 풀(Pool) 추산**:
   * MZC 연간 매출 약 `1.5조 원` 기준 ➔ AWS 관련 매출 비중 **80% = 약 `1조 2,000억 원/년`**
   * MSP 리셀 평균 매출총이익률(약 10%) 차감 시 **AWS에 지급하는 연간 순매입액 = 약 `1조 800억 원/년`**
   * 이 중 순수 컴퓨트(`EC2 범용 서버 + GPU 인스턴스`, 전체 청구액의 약 54%) 매입원가 = **연간 약 `5,800억 원`**
2. **목표치 '1/4(25%) 전환' 대입 시 필요 전력 용량**:
   * `5,800억 원`의 **1/4(25%)** = **연간 약 `1,450억 원` 규모의 클라우드 컴퓨트 매입액**
   * 자체 AIDC **1MW**가 수용 가능한 서버/GPU가 대체하는 AWS 동급 온디맨드/약정 원가는 **연간 약 `140억 ~ 160억 원/MW`** (고밀도 CPU 클라우드 + AI 추론/학습 GPU 혼합 기준)
   * 따라서 **1/4(`1,450억 원`)을 전부 자체 전환하려면 약 `9.0 ~ 10.3 MW`의 AIDC 용량이 필요**합니다.
   * **핵심 인사이트**: 대구 AIDC 1단계 자체 수요 배정분인 **`5MW`를 100% 가득 채우는 데에는 AWS 컴퓨트 매입의 1/4까지 갈 필요도 없이, 단 `1/10 ~ 1/8 수준(약 10~12%, 연 600억~720억 원 상당 매입분)`만 전환해도 공실률 0%로 완판**됩니다! 향후 1/4(25%)까지 전환 범위를 넓히면 2단계 증설분(+5MW)까지 MZC 단독 물량으로 소화 가능합니다.

### 3.3. 어떤 AWS 워크로드를 우선 전환해야 하는가? (기술·계약 리스크 필터링)

AWS의 관리형 PaaS(Aurora, DynamoDB, Lambda 등)에 강하게 묶인 고객 운영 DB를 억지로 옮기면 마이그레이션 비용과 장애 리스크가 큽니다. **전환 비용이 낮고 마진 개선 폭이 가장 큰 4대 타깃 워크로드(전체 컴퓨트의 약 25~30% 해당)**만 선별해도 5MW~10MW는 즉시 채워집니다.

1. **1순위 — AI 모델 학습 · 파인튜닝 · 배치 추론 및 LLM/VLA API 서빙 (`GPUaaS / TokenaaS`)**:
   * AWS `p5(H100)/g6` 인스턴스는 초고가이며 데이터 유입·유출(Egress) 비용이 막대함. Kubernetes(EKS) 컨테이너 기반이라 대구 AIDC로 엔드포인트만 바꾸면 즉시 전환 가능(마진 개선율 50%+).
2. **2순위 — 데이터 이그레스(Egress) 과다 발생 미디어·게임·유니티 렌더링 및 대용량 백업/아카이브**:
   * 대구 AIDC + Akamai 글로벌 CDN/엣지 조합으로 전환 시 AWS S3/CloudFront 대비 원가를 절반 이하로 절감 가능.
3. **3순위 — MZC 그룹 계열사 자체 SaaS/내부 시스템 및 엔터프라이즈 고객 개발·검증(Dev/Stage)·DR 환경**:
   * 미션크리티컬 본서비스(Prod)는 AWS 서울리전에 두더라도, 상시 켜두는 대규모 개발·테스트 클러스터와 재해복구(DR) 자원을 대구 AIDC로 내리는 하이브리드 구성.
4. **4순위 — AWS EDP(최소 사용 약정) 초과분(Over-usage) 흡수**:
   * 기존 AWS 약정 물량을 깎아 패널티를 무는 것이 아니라, **매년 15~20%씩 늘어나는 고객 클라우드 순증분과 GPU 신규 수요를 대구 AIDC로 우선 라우팅**하면서 차기 AWS EDP 갱신 시 할인율 인상 협상 카드로 활용.

### 3.4. 전략적 파급 효과: AWS 협상력 강화 & 해외 대형 테넌트 유치

* **[효과 1] AWS 대상 바게닝 파워(Bargaining Power) 역전**: 자체 10~40MW급 AIDC를 보유한 MSP는 단순 리셀러가 아닌 '하이브리드 인프라 사업자' 대우를 받게 되어, AWS가 워크로드 이탈을 막기 위해 프라이빗 프라이싱(Private Pricing) 할인 폭과 공동 영업 기금(MDF)을 확대할 수밖에 없습니다.
* **[효과 2] 해외 대형 테넌트 유치 및 MZC CapEx 감축 ('선 채움 후 교체' 전략)**:
  - 글로벌 네오클라우드나 빅테크 테넌트는 빈 부지(페이퍼 플랜)에는 절대 계약하지 않고 **"전력·인허가가 확정되고 공사가 진행 중인 확실한 센터"**에만 들어옵니다.
  - MZC 자체 수요 5MW로 먼저 센터 본PF를 성사시켜 착공한 뒤, 준공 전후로 해외 대형 테넌트와 고수익 코로케이션/GPUaaS 계약을 체결하면 **MZC가 직접 사야 할 GPU CapEx를 해외 테넌트의 자체 서버 반입 또는 장기 선수금으로 대체**하여 투자금 회수 기간을 절반으로 단축할 수 있습니다.

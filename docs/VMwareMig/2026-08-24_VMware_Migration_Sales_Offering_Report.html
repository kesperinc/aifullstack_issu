Executive Summary (경영진 요약) Key Highlights

글로벌 가상화 소프트웨어 시장을 20년 이상 독점해 온 VMware가 2023년 11월 Broadcom에 피인수된 이후, 영구 라이선스(Perpetual)를 전면 폐지하고 최소 3년 약정 기반의 구독형(Subscription) 모델을 강제 적용하였습니다. 특히 과금 단위가 CPU 소켓 단위에서 '물리 CPU 코어당 과금(CPU당 최소 16코어 보장)'으로 변경되고, 160여 개 제품군이 VCF/VVF의 2대 메가 번들로 강제 통폐합되면서 국내외 엔터프라이즈 고객의 계약 갱신 비용이 기존 대비 2~5배(최대 7배) 폭증하고 있습니다.

💡 메가존클라우드의 핵심 오퍼링 전략
메가존클라우드는 Nutanix Cloud Platform(NCI/AHV/NC2)과 Red Hat OpenShift(OCP/OpenShift Virt./OpenShift AI)를 결합하여 VMware 인프라 전체를 100% 대체합니다. 소프트웨어 라이선스 비용에서 60~70% 절감, 5개년 TCO 30~50% 절감을 실현함과 동시에, 온프레미스 데이터 주권을 완벽히 보호하며 차세대 하이브리드 AI 인프라로의 도약을 전담 지원합니다.
1. 고객 및 시장 환경 분석 (Market Context & Pain Points)

과거 국내 가상화 시장에서 VMware는 금융, 제조, 공공, 대기업 전반에 걸쳐 약 85~90%의 압도적인 점유율을 유지해 왔습니다. 그러나 Broadcom의 일방적인 가격 인상과 번들 강제화로 인해 2024~2026년 계약 갱신 시점을 맞이한 국내 기업의 40~60% 이상이 탈(脫)VMware를 경영진 핵심 과제로 추진하고 있습니다.

2. VMware 제품군 구조 및 Shelfware 맹점 분석

Broadcom은 수익성을 극대화하기 위해 VCF(풀스택 번들, 코어당 연 $100~$200+)와 VVF(경량 번들, 코어당 연 $50~$100) 단 두 가지만을 판매하고 있습니다. 국내 대다수 엔터프라이즈는 이미 고성능 외장 SAN 스토리지를 운영 중임에도 불필요한 vSAN 소프트웨어 비용을 지불해야 하며, 물리 방화벽을 쓰면서도 NSX 비용을 강제 지불하는 'Shelfware(미사용 잉여 기능 강매)' 현상에 시달리고 있습니다.

📦 VCF (VMware Cloud Foundation)

• 구성: vSphere + vSAN Enterprise + NSX + Aria Suite + Tanzu + HCX
• 과금: 코어당 연간 약 $100~$200+ (기존 대비 3~5배 폭증)
• 맹점: 외장 스토리지 및 물리 방화벽 보유 기업에 불필요한 기능 강매

📦 VVF (VMware vSphere Foundation)

• 구성: vSphere Enterprise Plus + vSAN Foundation (용량 제한) + Aria Lite
• 과금: 코어당 연간 약 $50~$100
• 맹점: NSX 및 Tanzu가 제외되어 컨테이너 및 클라우드 네이티브 확장 불가

3. Red Hat OpenShift & Nutanix 대체 영역 1:1 정밀 매핑

Nutanix Cloud Platform과 Red Hat OpenShift의 결합은 VMware의 레거시 가상화 인프라부터 차세대 클라우드 네이티브 및 AI 인프라까지 전 영역을 완벽하게 1:1 대체합니다.

4. 국내외 경쟁 가상화 및 클라우드 솔루션 심층 분석 Competitive Matrix

탈VMware 시장에서 Nutanix 및 OpenShift 외에도 글로벌 및 국내 토종 솔루션들이 거론되고 있으나, 각 솔루션마다 기술적 한계와 제약사항이 뚜렷합니다.

🌐 Microsoft Azure Stack HCI / Azure Local

• 강점 : 기존 Windows Server 라이선스 혜택(AHB) 연계 용이
• 한계 : Azure 구독 필수 및 30일 이상 인터넷 단절 시 인증 제약(폐쇄망 도입 난항), AWS/GCP 멀티클라우드 연동 불가, 제한적인 WSSD 하드웨어 호환성

🇰🇷 오케스트로 (Okestro) - 콘트라베이스 (Contrabass)

• 강점 : 국내 공공기관 국산화 및 보안 적합성(CC인증) 획득, 국내 밀착 지원
• 한계 : 글로벌 CSP(AWS/Azure)와의 워크로드 양방향 이관 한계, SAP HANA 등 글로벌 엔터프라이즈 ISV 인증 부족, OpenStack 고유의 복잡한 운영 공수

🌐 SUSE Harvester / Rancher

• 강점 : KubeVirt 기반 경량 HCI, 저렴한 도입 비용
• 한계 : 스토리지 데이터 서비스(중복제거/압축) 성숙도 미흡, 국내 대형 금융/제조 계정계 검증 레퍼런스 부족

🇰🇷 이노그리드 (Innogrid) - 클라우드잇 (Cloudit)

• 강점 : 공공 조달 및 지자체 클라우드 전환 사업 특화
• 한계 : 대규모 엔터프라이즈 멀티 테넌시 및 고성능 I/O 워크로드 처리 검증 부족, 엔터프라이즈 AI GPU 오케스트레이션 미흡

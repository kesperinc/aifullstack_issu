# PPT 템플릿(Dell Distributor Proposal) 기반 HTML 슬라이드 덱 완벽 적용 계획서

## 1. 개요 및 목적
사용자가 제공한 파워포인트 템플릿(`Dell_Distibutor_proposal.pptx`)의 디자인 시스템과 레이아웃을 15분 30슬라이드 영문 덱 HTML(`K-AI/2026-09-09_Korea_Sovereign_AI_Strategy_Deck.html`)에 100% 완벽하게 적용합니다. 브라우저에서 열었을 때 실제 최고급 기업 프레젠테이션 쇼를 진행하는 것과 동일한 시각적 퀄리티와 조작성을 제공합니다.

---

## 2. PPT 템플릿 기반 핵심 개선 사항

### 2.1 템플릿 디자인 시스템 & 컬러 팔레트 일체화
- **섹션 배지**: PPT 템플릿의 고유 색상인 Deep Corporate Navy (`#0B2A68`) 및 캡슐 태그 적용.
- **슬라이드 타이틀**: Navy Bold (`#002060` / `#002B49`), 서브타이틀 액센트 (`#1760CB` / `#0066FF`).
- **카드 스타일**: White Card Canvas (`#FFFFFF`), 섬세한 테두리 (`#E2E8F0`), 좌측 또는 상단 4px 그라디언트 액센트 바, 원형 번호 배지 (`#0066FF`), 마우스 호버 시 은은한 부유 애니메이션.
- **하단 푸터 바**: 템플릿의 일관된 좌우 정렬 푸터 (좌측: 세션명 및 기관명 / 우측: `Slide X / 30`).

### 2.2 슬라이드 유형별 특화 템플릿 레이아웃 (Template Layout Variants)
1. **Cover Slide (Slide 01)**:
   - 템플릿의 프리미엄 다크 네이비 테마 (`#001A30` ~ `#002B49`)
   - 16:9 서울 소버린 AI 키 비주얼 (`slide01_cover_sovereign_ai.jpg`)
   - UCLA Anderson & MegazoneCloud 골드/시안 메타데이터 카드
2. **Contents / Agenda Slide (Slide 02)**:
   - 템플릿의 `CONTENTS` 레이아웃을 살린 4대 아젠다 모듈 카드 그리드
3. **2x2 Grid Card Layout (4개 불릿 슬라이드)**:
   - 4개 항목을 단순 1열 수직 나열이 아닌, PPT 템플릿 특유의 균형 잡힌 **2행 x 2열(2x2)** 사각 그리드 카드로 배치하여 공간 활용 및 가독성 극대화.
4. **3-Column / 1-Column Layout (3개 불릿 슬라이드)**:
   - 3개 항목은 넓은 가로 3열 카드 또는 여유 있는 수평 스트립 카드로 배치.
5. **Split Layout (좌측 불릿 카드 + 우측 16:9 대형 그래픽)**:
   - AI 생성 이미지 5종이 포함된 슬라이드(Slide 1, 7, 19, 24, 28)에 최적화된 2단 분할 레이아웃.
6. **Executive Metric Scorecard (Slide 25)**:
   - 75% Capex Cut, 3.2kW Power, 3x Latency, 100% Air-Gapped 등 핵심 지표를 대형 콜아웃 배지와 함께 강조하는 스코어카드 템플릿.
7. **Closing & Q&A Slide (Slide 30)**:
   - 발표 피날레를 장식하는 다크 프리미엄 Q&A 레이아웃.

### 2.3 프레젠테이션 자동 스케일링 엔진 (Scale-to-Fit Engine)
- 프로젝터, 노트북, 4K 모니터 등 어떤 화면 해상도에서도 16:9 (1920x1080 기준) 슬라이드 캔버스가 중앙에 왜곡 없이 꽉 차도록 `window.resize` 시 자동 scale() 트랜스폼 연산.
- 스크롤바 없는 클린 프레젠테이션 뷰.

### 2.4 인터랙티브 기능 강화
- 키보드 네비게이션: `◀`, `▶`, `Space`, `Home`, `End`
- 발표자 스피커 대본 모달 드로어 (`S` 키)
- 30슬라이드 전체 조감도 그리드 뷰 (`G` 키)
- 브라우저 전체화면 전환 (`F` 키)
- 15분 세션 카운트다운 타이머 (일시정지/재개 지원)

## 3. 검증 계획
1. 브라우저 서브에이전트(`browser_subagent`)를 통해 HTML 파일을 로컬에서 열고, 슬라이드 1(커버), 슬라이드 2(아젠다), 슬라이드 7(이미지 분할), 슬라이드 25(ROI 메트릭), 슬라이드 30(Q&A) 등을 전환하며 레이아웃과 폰트, 카드 스타일이 PPT 템플릿과 일치하는지 스크린샷 캡처 및 시각적 검증.
2. 발표자 대본(`S`), 인덱스 그리드(`G`), 타이머 동작 확인.
3. 문서 및 Git 커밋/푸시 반영.
